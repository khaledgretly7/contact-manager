## 📌 Overview

The Contact Manager is a full-stack web application that allows users to create, view, update, and delete personal or professional contacts. It uses MongoDB Atlas as the primary NoSQL cloud database, demonstrating the power and flexibility of document-based data storage in a modern web application.

---

## ✨ Features

- ✅ Full CRUD — Create, Read, Update, Delete contacts
- 🔍 Real-time search by name, email, or phone number
- 🎨 Auto-generated color-coded avatars from contact initials
- 🌑 Professional dark UI with smooth animations
- 💬 Toast notifications for every action
- ☁️ Cloud-hosted MongoDB Atlas database
- 🔒 Secure credential management via environment variables
- ⌨️ Keyboard shortcut — Escape key closes modal

## ⚙️ How to Run Locally

### Prerequisites
- Node.js v18 or higher
- A free MongoDB Atlas account

### Steps

1. Clone the repository:
```bash
git clone https://github.com/khaledgretly7/contact-manager.git
cd contact-manager
```

2. Install dependencies:
```bash
npm install
```

3. Create a `.env` file in the root folder:
MONGO_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/contactmanager
PORT=5000

4. Start the server:
```bash
node server.js
```

5. Open your browser at:
http://localhost:5000

You should see:
✅ Connected to MongoDB!
🚀 Server running on port 5000

## 📡 API Endpoints

| Method | Endpoint | Description | Response |
|--------|----------|-------------|----------|
| GET | `/api/contacts` | Get all contacts | 200 + JSON array |
| POST | `/api/contacts` | Create new contact | 201 + new document |
| PUT | `/api/contacts/:id` | Update contact by ID | 200 + updated doc |
| DELETE | `/api/contacts/:id` | Delete contact by ID | 200 + message |

## 🗂️ Data Model

Each contact is stored as a MongoDB document with the following structure:

```json
{
  "_id":       "ObjectId (auto-generated by MongoDB)",
  "name":      "Ahmed Hassan",
  "email":     "ahmed@email.com",
  "phone":     "+20 100 000 0000",
  "address":   "Cairo, Egypt",
  "createdAt": "2026-05-04T00:00:00.000Z"
}
```

---

## 🔒 Security

- MongoDB URI and password stored in `.env` — never committed to version control
- `.gitignore` excludes `.env` and `node_modules/`
- Mongoose schema validation rejects documents missing required fields
- CORS middleware controls which origins can access the API
- MongoDB Atlas encrypts all data in transit using TLS/SSL
